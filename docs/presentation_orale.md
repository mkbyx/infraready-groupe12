# Plan de la démonstration finale (≈ 15 min)

1. **Architecture** (2 min) : schéma, rôles, plan IP, flux.
2. **Automatisation** (5 min) : inventaire, playbooks Linux/Windows, 2e exécution à `changed=0`, `verification.yml`.
3. **Supervision** (4 min) : dashboard (CPU, mémoire, stockage, disponibilité), provenance des métriques, alerte démontrée.
4. **Diagnostic d'incident** (3 min) : symptôme, tests/journaux, cause, correction, retour à la normale.
5. **Sécurité & CI** (1 min) : Vault, moindre privilège, run GitHub Actions vert. Limites connues.
